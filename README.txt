# Infinity Store — Bootstrap 5

A responsive clothing-store homepage built with Bootstrap 5.

## Files
- `index.html` — page structure and Bootstrap components
- `css/style.css` — custom styling and responsive layout
- `js/script.js` — small demo interactions
- `img/` — create this folder if you want to download and store images locally

## Run
Open `index.html` in your browser. Bootstrap, Font Awesome, Google Fonts, and the demo photos currently load from online CDNs/URLs, so an internet connection is needed.

## Notes
- The language dropdown is a visual front-end example; it does not translate the site yet.
- Product prices and add-to-cart buttons are demo content; there is no checkout or backend.
- Replace the demo image URLs and links with your own store assets and pages.

## Additional pages
- `summer.html` — Summer collection page
- `winter.html` — Winter collection page
- `shop.html` — all-products page
- `contact.html` — contact details and contact form

The contact form currently demonstrates front-end validation and a confirmation message only. To receive messages by email, connect it to a backend or a form-handling service.
